# Backend

Este diretório contém a aplicação Django: `apps/`, configurações em `config/`, comandos auxiliares em `scripts/` e o ponto de entrada `manage.py`.

Execute comandos Django a partir da raiz do repositório:

```bash
python backend/manage.py runserver
python backend/manage.py migrate
```

O `requirements.txt` fica na raiz para o build da Vercel instalar as dependências do backend.
